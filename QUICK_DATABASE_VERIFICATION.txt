════════════════════════════════════════════════════════════════════════════════
                    TROUBLESHOOTING IF FAIL
════════════════════════════════════════════════════════════════════════════════

❌ Query 1: Tabel not found
  → Database schema tidak ada
  → Need to run migration
  → Check: backend/migrations folder

❌ Query 3: Count is 0
  → Database kosong
  → Need to seed data
  → Or: Check if data is in wrong database

❌ API error (curl step)
  → Backend not connected to Supabase
  → Check: SUPABASE_URL & SUPABASE_SERVICE_ROLE_KEY di backend/.env
  → Verify: Credentials valid

❌ Dashboard still blank
  → Data might be cached
  → Try: Hard refresh Ctrl+Shift+R
  → Or: Clear browser cache completely

❌ "Connection refused" at Rclone
  → Alist still not running
  → Check: ENABLE_ALIST=true applied?
  → Backend logs should show: [Alist] ✅ Service initialized
