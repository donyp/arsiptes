    - No Alist installation
    - Only exposed port 8080

    - Install Alist from GitHub releases

    - Wait for port 5244 to listen
    - Then start Node.js

  Result:
    ✅ Alist available on 5244
    ✅ File uploads work
    ✅ Logs to /app/data/log/alist.log

STARTUP SEQUENCE (New)
═══════════════════════════════════════════════════════════════════

1. Docker Container Starts
   └─ Installs Alist from GitHub during build

2. Container Runs start.sh
   ├─ Create directories
   ├─ Generate rclone.conf
   ├─ Start Alist (background): nohup /usr/local/bin/alist server
   ├─ Wait for port 5244 (health check): nc -z localhost 5244
   ├─ Log results to /app/data/log/alist.log
   └─ Then start Node.js

3. Services Running
   ├─ Alist: localhost:5244 (internal, port 5244)
   ├─ Node.js: 0.0.0.0:8080 (external, port 8080/7860)
   └─ Rclone: (connects to Terabox)
