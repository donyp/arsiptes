================================================================================
  TROUBLESHOOTING
================================================================================

IF FILE LIST STILL NOT SHOWING:

1. Check Browser Console (F12):
   - Look for RED error messages
   - Report exact error text

2. Check Network Tab (F12 → Network):
   - Reload page
   - Look for: GET /api/files request
   - Should return Status: 200 with file data
   - If status is 401/403, authentication issue
   - If status is 500, server error

3. Try Hard Refresh:
   - Windows: Ctrl+Shift+R
   - Mac: Cmd+Shift+R
   - Or: Ctrl+F5

4. Clear All Cache:
   - Close all browser tabs with dashboard
   - Clear browser cache completely (Settings → Clear browsing data)
   - Reopen http://localhost:5000/dashboard.html

5. Check Server Logs:
   - Backend server should show:
     "✅ Backend listening on port 5000"
   - If not, server might have crashed

IF YOU SEE ERRORS:

Common Issues:
  
  Error: "API object not defined"
  → Check: js/auth.js is loaded (check Network tab in DevTools)
  → Solution: Hard refresh with Ctrl+Shift+R
  
  Error: "Token tidak ditemukan" (Token not found)
  → Check: You're logged in at http://localhost:5000
  → Solution: Login page should redirect to dashboard automatically
  
  Error: "CORS error" or "Access blocked"
  → Check: Backend running on port 5000
  → Solution: Run: node backend/server.js
  
  Error: "500 Internal Server Error"
  → Check: Backend logs in terminal
  → Solution: Check error message in server output
