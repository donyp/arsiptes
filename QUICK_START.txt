🌐 OPEN WEB
═════════════════════════════════════════════════════════════════════

  Once server is running:
  ► Open browser: http://localhost:5000

✅ EXPECTED OUTPUT
═════════════════════════════════════════════════════════════════════

  ✓ Backend listening on port 5000
  ✓ Browser shows login page (NOT blank white)
  ✓ Can enter credentials to login

❌ TROUBLESHOOTING - If web still blank white
═════════════════════════════════════════════════════════════════════

  1. Kill old processes:
     ► Double-click: kill-old-servers.bat
     ► OR: .\cleanup-processes.ps1

  2. Restart server:
     ► Double-click: start-server.bat

  3. Check port is free:
     ► netstat -ano | Select-String ":5000"
     ► If something is using it, close that application

  4. Check logs:
     ► Open: server-restart.log
     ► Look for [ERROR] messages

  5. Check dependencies:
     ► cd backend
     ► npm install
     ► npm start
