════════════════════════════════════════════════════════════════

1. User requests: /api/preview/zona-1/TOKO-CIANJUR/INVOICE/file.pdf

2. Endpoint maps path to local file:
   /backend/local_files/zona-1/TOKO-CIANJUR/INVOICE/file.pdf

3. Checks if file exists
   - If YES: Stream file with proper PDF headers
   - If NO: Serve sample file for testing (fallback)

4. Browser receives PDF and displays inline

5. Backend logs show file was served successfully
